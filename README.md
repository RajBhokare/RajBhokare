## 💻 Detailed Projects

### 🧠 1. Quizzer
> **Event:** Vortexa 2025

Quizzer is an intelligent video summarizer and quiz generator designed to transform educational videos into concise summaries and dynamic assessment quizzes using automated transcript processing.

- 🎥 **Video-Based Learning:** Streamlines long video content into actionable educational assets
- 📝 **Transcript Processing:** Extracts and parses speech-to-text transcripts using **AssemblyAI**
- 🧠 **Summary Generation:** Synthesizes structured summaries from processed video transcripts
- ❓ **Quiz Generation:** Automatically crafts interactive quizzes based on video content
- 📱 **Responsive Interface:** Clean UI built with responsive layout styling

**Tech Stack:** `HTML` `CSS` `JavaScript` `EJS` `Bootstrap` `AssemblyAI`  
🔗 **Repository:** [github.com/RajBhokare/Quizzer](https://github.com/RajBhokare/Quizzer)
